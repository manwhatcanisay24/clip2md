# Privacy Policy / 隐私政策

**Effective date / 生效日期：2026-10-30**

## English

Clip2MD is designed to process web content locally. The v0.1.0 extension does not operate a server and does not send article content, generated Markdown, or usage analytics to the developer or third parties.

### Data processed

- **Current page content and metadata:** read only after you open Clip2MD and request extraction. Processing happens in your browser to create the preview.
- **Preferences:** interface language and whether to include the title/source link are stored with the browser's local extension storage.
- **Clipboard and downloads:** content is transferred only when you click Copy or Download. Your browser and operating system handle those actions.

Clip2MD does not store article history or original HTML in v0.1.0. It does not use cookies, accounts, advertising identifiers, remote fonts, analytics, or tracking pixels. Images remain remote URLs in generated Markdown; opening that Markdown in another application may cause that application to request the images from their original hosts.

### Network access

The extension itself makes no remote API requests. A page may have its own independent network behavior, which Clip2MD does not control.

### Retention and deletion

Generated Markdown is kept only in the open popup and is not added to a persistent history. Downloaded files and clipboard contents remain under your control. To remove saved preferences, clear the extension's site/storage data in your browser or uninstall Clip2MD.

### Changes

Material privacy changes will be documented in the release notes and this file.

## 中文

Clip2MD 以本地处理为设计原则。v0.1.0 不运行自有服务器，不会向开发者或第三方发送网页正文、生成的 Markdown 或使用统计。

### 处理的数据

- **当前页面正文与元数据：**仅在你打开 Clip2MD 并请求提取后读取，在浏览器内生成预览。
- **偏好设置：**界面语言、是否包含标题和原始链接，通过浏览器扩展本地存储保存。
- **剪贴板与下载：**仅在点击复制或下载时传输，由浏览器和操作系统处理。

v0.1.0 不保存文章历史或原始 HTML，不使用 Cookie、账号、广告标识、远程字体、分析统计或跟踪像素。生成的 Markdown 中图片仍使用远程 URL；在其他应用中打开文件时，该应用可能会向图片原始服务器发起请求。

### 网络访问

扩展自身不发起远程 API 请求。原网页可能具有独立的网络行为，Clip2MD 不控制这些行为。

### 保留与删除

生成的 Markdown 仅保留在当前弹窗，不写入持久历史。下载文件和剪贴板内容由你自行管理。可在浏览器的扩展数据管理中清除 Clip2MD 存储，或卸载扩展以删除本地偏好。

### 政策变更

重要的隐私变化会同步记录在发布说明和本文件中。
