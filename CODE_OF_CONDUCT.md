# Code of Conduct / 行为准则

## Our commitment / 我们的承诺

We are committed to a welcoming, harassment-free project for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, experience, education, nationality, personal appearance, race, religion, sexual identity, or orientation.

我们致力于为所有人提供友好、无骚扰的参与环境，不因年龄、体型、残障、族裔、性别认同与表达、经验、教育、国籍、外貌、种族、宗教、性认同或性取向而区别对待。

## Expected behavior / 期望行为

- Be respectful, constructive, and patient. / 保持尊重、建设性和耐心。
- Welcome different viewpoints and useful technical criticism. / 欢迎不同观点和有依据的技术讨论。
- Accept responsibility and learn from mistakes. / 对错误负责并从中学习。
- Focus on what benefits the community and users. / 关注社区和用户的整体利益。

Unacceptable behavior includes harassment, insults, discriminatory comments, unwelcome sexual attention, doxxing, sustained disruption, and publishing private information without permission.

不可接受的行为包括骚扰、侮辱、歧视、不受欢迎的性关注、人肉搜索、持续扰乱讨论，以及未经许可公开他人私人信息。

## Enforcement / 执行

Maintainers may remove, edit, or reject comments, commits, issues, and other contributions that violate this code. They may temporarily or permanently ban behavior that is threatening, harmful, or repeatedly disruptive.

维护者可删除、编辑或拒绝违反本准则的评论、提交、Issue 和其他贡献，并可对威胁、伤害或反复扰乱秩序的行为采取临时或永久封禁。

Report conduct concerns through the maintainer's private contact channel on GitHub. Do not disclose another person's private information in a public issue. Reports will be reviewed with discretion and respect for everyone involved.

如需报告行为问题，请通过维护者在 GitHub 上的私密联系方式处理，不要在公开 Issue 中披露他人私人信息。维护者将谨慎、公正地处理相关报告。

## Scope / 范围

This code applies in project spaces and when representing the project in public. / 本准则适用于项目空间及代表项目参与公共活动的场景。

This policy is inspired by the Contributor Covenant, version 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
