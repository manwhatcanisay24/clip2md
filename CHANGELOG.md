# Changelog / 更新日志

All notable changes are documented here. This project follows Semantic Versioning.
本项目遵循语义化版本规范，在此记录重要变化。

## [v0.1.0] - 2026-10-30

### Added / 新增

- Initial Manifest V3 extension for Chrome and Edge. / 首个支持 Chrome 和 Edge 的 Manifest V3 扩展。
- On-demand article and metadata extraction with Mozilla Readability. / 基于 Readability 的主动正文与元数据提取。
- Markdown conversion for common article elements and fenced code languages. / 支持常见正文元素及代码语言标记的 Markdown 转换。
- Editable preview, clipboard copy, and UTF-8 Markdown downloads with safe filenames. / 可编辑预览、复制及安全文件名的 UTF-8 下载。
- Persistent title/source options and English / Simplified Chinese UI. / 持久化标题与来源设置，以及中英双语界面。
- Manual fallback for unreadable and unsupported pages. / 不支持或提取失败页面的手动兜底。
- Six local fixtures, 24 unit tests, real Edge end-to-end verification, CI, bilingual documentation, and release screenshots. / 6 个本地样本、24 项单元测试、真实 Edge 端到端验收、CI、双语文档与发布截图。

### Known limits / 已知限制

- Selection clipping, Front Matter, templates, history, image archiving, advanced tables, and GitHub content saving are planned for later releases. / 选区、Front Matter、模板、历史、图片归档、高级表格和 GitHub 内容保存留待后续版本。
